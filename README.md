# Customer Intelligence ML Platform

An end-to-end Machine Learning platform for customer analytics.

## Goal

Build a production-oriented ML system that:

- segments customers using unsupervised learning
- predicts customer churn using supervised learning
- tracks experiments with MLflow
- exposes predictions through FastAPI
- demonstrates ML Engineering best practices
